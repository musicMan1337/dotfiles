## Formula Structure

All expense tables follow this pattern:
- **Column layout**: Label | Monthly | Per Check | Notes
- **Per Check formula**: `=Monthly/2` (monthly column divided by 2)
- **Sub-totals**: `=SUM(item rows)` for both Monthly and Per Check columns
- **Grand totals**: `=SUM(sub-total rows)` across sub-sections

Income column:
- **Salary**: Annual is hardcoded ($107,000), Per Check = `=Annual/24`
- **Pre-tax/After-tax/Tax totals**: `=SUM(item rows)` for Per Check column
- **Tax % total**: `=Total Taxes / Gross Per Check`
- **Total Take-Home**: `=Gross - PreTax - AfterTax - Taxes`
- **Wells Fargo deposit**: `=Take-Home - Ally deposit - Doge deposit`
- **Unallocated**: `=Wells Fargo deposit - Fixed total - Discretionary total`

## How to Add an Expense Row

Adding a row requires regenerating the affected table because inserting rows in openpyxl with merged cells and formulas is fragile. The recommended approach:

1. Read the current Excel file with `openpyxl` (data_only=False to preserve formulas)
2. Identify which section the new expense belongs to
3. Use `lib/budget-regen.py` to regenerate the entire sheet with the new data
4. Regenerate the markdown file from the same data

## How to Update Salary

Salary changes require a paystub because tax withholding amounts change with salary. The process:
1. User provides a paystub PDF
2. Read the PDF to extract: gross per check, all tax line items, all deduction line items
3. Update the salary (annual) cell
4. Update all tax amounts
5. Update all deduction amounts
6. Formulas recalculate everything else

## Markdown Sync

The markdown file must mirror the Excel data. After any Excel change, regenerate the markdown. The markdown structure:

1. Income section (gross, deductions, taxes, deposit split)
2. Ally Account (housing, auto & debt, savings, lion + subscriptions)
3. Doge Account (pet expenses)
4. Wells Fargo (fixed, discretionary, unallocated)
